      Quan sát một sự kiện mới

      Thêm log mẫu để xem biểu đồ và bảng cập nhật. Muốn kiểm tra lượt xem sản phẩm, mở cửa hàng rồi quay lại dashboard trong cùng tab.

      Mỗi lần mở trang tạo 1.200 log mẫu. Không phát log tự động, không đo latency và không gửi dữ liệu đến server.
